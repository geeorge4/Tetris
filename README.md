# 🎮 RG Mini Games (Telegram Mini App)

**RG Mini Games** — это коллекция классических мини-игр, встроенная прямо в Telegram. Проект создан для мобильных устройств и работает как полноценное приложение внутри мессенджера.

**RG Mini Games** is a collection of classic mini-games built right into Telegram. The project is designed for mobile devices and works as a full-fledged app inside the messenger.

---

## 🕹️ Игры / Games
- 🔢 **Угадай число / Guess the Number**: Классическая игра на угадывание числа от 1 до 100.
- 💣 **Сапер / Minesweeper**: Упрощенная версия 5x5, где нужно найти все мины.
- 🧱 **Тетрис / Tetris**: Мини-версия легендарной игры с сенсорным управлением.

## 🚀 Возможности / Features
- 📱 **Mobile-First**: Полная адаптация под экраны телефонов (большие кнопки, вибрация).
- 🎨 **Dark Theme**: Стильный темный интерфейс в цветах Telegram.
- ⚡ **Fast & Lightweight**: Никаких тяжелых библиотек, только чистый HTML, CSS и JS.
- 🕹 **Haptic Feedback**: Тактильный отклик (вибрация) при нажатиях.
